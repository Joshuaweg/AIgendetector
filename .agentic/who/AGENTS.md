# who/ — Agent Guide

## What's Here

People, teams, and organizations involved in AIgendetector: researchers, collaborators, deployment contacts, dataset providers.

## Working Rules

- One file per person or organization
- Filename pattern: `person_firstname_lastname.md` or `org_name.md`
- Required frontmatter: `type`, `created`, `updated`, `last_edited_by`, `tags`
- Read before write; set `updated` and `last_edited_by` on every edit

## When to Add Files Here

- A new collaborator joins the project
- An external organization provides data or infrastructure
- You need to track contact information or role assignments
